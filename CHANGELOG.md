# Changelog

## [1.0.1] - 2026-10-16

### Fixed

- Load and display the saved image preview as soon as the main window opens,
  without requiring the user to switch slots first.
- Repaint the image preview immediately after loading or changing its bitmap.
- Redraw the title, version label, and cursor icon when the theme changes, and
  paint the cursor icon background with the active theme color.
- Reduce text redraw artifacts when resizing the window.

### Changed

- Refresh the rusty-cursor icon asset used by the application.

## [1.0.0]

- Initial versioned release.
